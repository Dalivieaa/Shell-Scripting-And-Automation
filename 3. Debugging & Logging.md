## Debugging & Logging

### 1. Journalctl (Log Sistem)

| No | Langkah | Detail |
| :---: | :--- | :--- |
| **1** | `Lihat Semua Log` | Tampilkan seluruh catatan log sistem: `journalctl` |
| **2** | `Log 30 Menit Terakhir` | Filter log setengah jam terakhir: `journalctl --since "30 minutes ago"` |
| **3** | `Log Layanan Tertentu` | Filter log service spesifik (contoh cron): `journalctl -u cron` |
| **4** | `Pantau Real-time` | Pantau log secara langsung (*live stream*): `journalctl -f` |

### 2. Dmesg (Log Kernel)

| No | Langkah | Detail |
| :---: | :--- | :--- |
| **1** | `Pesan Kernel` | Tampilkan pesan aktivasi kernel hardware: `dmesg` |
| **2** | `Log Kernel Terperinci` | Tampilkan log sistem spesifik level kernel: `sudo journalctl -k` |
