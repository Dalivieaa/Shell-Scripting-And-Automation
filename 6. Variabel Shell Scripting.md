## A. Variabel

Variabel digunakan untuk menyimpan data yang dapat dipanggil kembali.

```bash
1. Deklarasi Variabel
   Menyimpan data teks maupun angka ke dalam variabel.

nama="Box"
umur=19

echo "Nama saya $nama, umur saya$umur"

2. Input Pengguna
   Mengambil input ketikan pengguna menggunakan perintah read.

echo "Masukkan nama anda:"
read nama

echo "Selamat datang, $nama"

3. Operasi Matematika
   Melakukan operasi hitung aritmetika dalam variabel.

x=10
y=5

hasil=$((x + y))
echo "Hasil penjumlahan: $hasil"
