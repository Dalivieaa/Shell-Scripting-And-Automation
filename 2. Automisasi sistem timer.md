## Automasi dengan Systemd Timers

| No | Langkah | Detail |
| :---: | :--- | :--- |
| **1** | `Buat Service File` | Buat file unit layanan: `sudo nano /etc/systemd/system/nama_tugas.service` |
| **2** | `Buat Timer File` | Buat file konfigurasi pewaktu: `sudo nano /etc/systemd/system/nama_tugas.timer` |
| **3** | `Aktifkan Timer` | Jalankan dan aktifkan timer secara otomatis: `sudo systemctl enable --now nama_tugas.timer` |
| **4** | `Periksa Status` | Verifikasi status operasional timer: `systemctl status nama_tugas.timer` |
